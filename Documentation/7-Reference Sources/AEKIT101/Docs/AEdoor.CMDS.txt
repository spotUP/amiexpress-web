/**************************** GET/SET Values from System ***********************/

The following are AmiExpress Door Commands, with these you may get or
set Data in AmiExpress using the getuserstring or putuserstring.

JH_BBSName        Get     the BBS Name
JH_Sysop          Get     the Sysop's Name
DT_NAME           Get/Set the User's Name
DT_PASSWORD       Get/Set the User's Password
DT_LOCATION       Get/Set the User's Location
DT_PHONENUMBER    Get/Set the User's PhoneNumber
DT_SLOTNUMBER     Get     the User's SlotNumber
DT_SECSTATUS      Get/Set the user's security level
DT_MESSAGESPOSTED Get     number of messages a user has posted
DT_UPLOADS        Get/Set the number of uploads a user has
DT_DOWNLOADS      Get/Set the number of downloads a user has
DT_TIMESCALLED    Get/Set the number of times a user has called
DT_TIMELASTON     Get/Set the time a user was last on , this is in packed
                  form.
DT_TIMEUSED       Get/Set the time used, this is in packed form.
DT_TIMELIMIT      Get/Set the amount of time a user is allowed online
                  per day. (Packed)
DT_TIMETOTAL      Total amount of Time a user has been online in packed 
                  form.
DT_BYTESUPLOAD    Get/Set the number of Bytes a user has uploaded
DT_BYTEDOWNLOAD   Get/Set the number of Bytes a user has downloaded
DT_DAILYBYTELIMIT Get/Set the number of Bytes a user can download per day.
DT_DAILYBYTEDLD   Get/Set the number of Bytes download today
DT_EXPERT         Get/Set expert mode
DT_LINELENGTH     Get/Set user's line length
ACTIVE_NODES      Get     a list of Active nodes.
DT_DUMP           Dump a user's data structure to a specified file.
BB_CONFNAME       Get/Set the current conference name a user is in.
BB_CONFLOCAL      Get/Set the current conference location a user is in.
BB_LOCAL          Get/Set the current BBS location.


This is the structure definition for messages going between the doors and
AmiExpress.

struct JHMessage
{
 struct Message Msg;
  char String[200];
  int Data;
  int Command;
  int NodeID;
  int LineNum;
};


Provided in this archive is the Lattice/Manx glue routines for making doors
for AmiExpress.

The first thing a door should do, is register itself with AmiExpress by
issuing the command:
  
   Register(argv[1][0]-'0'); 

When you are ready to close the door, you need to issue the command
ShutDown(); this is detach the door from AmiExpress. Then you must
provide your own function for cleaning up files etc... Called end();

Please note that if there is a KeyBoard timeout or if someone looses
carrier, the bbs will automatically call ShutDown(); and end(); 
remember you must write your own end(); function.

sendmessage(string,1)  --- This command will send a string to AmiExpress
                           with a linefeed/carrage return combination.
sendmessage(string,0)  --- This command will send a string to AmiExpress
                           without a linefeed/carrage return combination.
ConOnly(string,0)
ConOnly(string,1)      --- Works the same as sendmessage but only displays
                           it to the console and not the serial port.
prompt(string,store,5) --- This is prompt a user with 'string' and wait for
                           a user to type in a response no more than 5
                           characters and store the response in 'store'.
hotkey(string,store)   --- This is prompt a user with 'string' and wait for
                           any key to be pressed, the pressed key will not
                           show up on the screen but the response will be
                           stored in 'store' with an embedded '\0'

getuserstring(store,cmd) --- This command will ask amiexpress a question
                             'cmd' (Please refer to above DT_ commands) and
                             store the result in 'store'
putuserstring(string,cmd) -- This command will set a value in AmiExpress
                             with 'string' based on the 'cmd' (Please refer
                             to the above DT_ commands)
showgfile(string)        --- This command will attempt to display a file
                             'string' to the screen. Note this should not
                             contain the extensions '.txt' or '.Gr1' the
                             showgfile will automatically append the 
                             extension. Sorry about the .GR1 extension but
                             at the time of writing the door protocol I 
                             was planning on going with the Paragon
                             standard.
FlagFile(string)         --- This will allow you to flag files for a user
                             to download when they exit the door. Please
                             note that the file must me in the path for it
                             to be downloaded.


NOTE: All values sent and received from AmiExpress must be in a string.
      the string is defined as a character array 200 in length.

here is a sample door which will say hello to the user

---------------------------------------------------------------------
#include <exec/types.h>
#include <exec/exec.h>
#include <stdio.h>
#include <stdlib.h>

main(int argc,char *argv[])
{
   char Name[100];
   Register(argv[1][0]-'0');
   getuserstring(Name,DT_NAME);
   sm("Hello ",0);
   sm(Name,0);
   sm(".",1);
   ShutDown();
   end();
}

end()
{
  exit(0);
}

I have provided the glue routines to make this work. to link the above
code you would have to do the folowing in MANX. Assuming this file
name was called simple.c

CC Simple.c
ln Simple.o AEManx.o -lc -o Simple

In SASC,

lc Simple.c
blink lib:c.o+Simple.o+AESasc.o to Simple Library lib:lc.lib+lib:amiga.lib

both the above would create a file called Simple.
