This /X DoorKIT was created because there has been a NEED for it for a long
time now and some people were still searching for the /X includes and some
simple examples to get them started.

It's our intention to Update this Archive regulary to Add more Examples and
Update the Docs/Includes.
Furthermore a /X-FAQ (Frequent Asked Questions) will be Added in future
releases.

For now only SAS/C 6.xx is supported. When more Info is available then support
for more Compilers/Assemblers will be added (If it's needed).

SOURCES:
~~~~~~~~

Almost all sources can be compiled with SAS 6.0 - 6.03, there are some sources
which are included just to see how other programmers are working.

Every source includes a SmakeFile, with it it's easy to compile the source.
Just CD to the Source-Directory and enter:  smake
If smake can't be found then check you paths or install SAS properly!
