*** AEHelp ***  AmiExpress Help Door by NAMELESS

My current version of AmiExpress has a help option (H) but I've found
that that only reads and displays a HUGE text file, if the user wants
help for just the Z command they got to read pages of other garbage,
so I created this little door that will let them get HELP for any
of the amiexpress commands (almost) immediatly.

This door will let your users who are unfamiliar with AmiExpress
get help for specific commands.  This initial version has the help
for all of the commands hard coded within it, I know this makes it
hard for ya to change the help for each command, but I plan later
(If I get a chance) to let it read the help from a text file, for
right now though this is the way I wanted it for my BBS (Since I can
quickly change the text and recompile, hehehe).


*** SETTING UP THIS DOOR ***

(1) Copy the AEHELP file to your DOORS: directory (usually BBS:doors)

(2) Append the following line to your BBS:Commands/CustomCommands file,
    This line is the same as the customcommands.append file attached
    to this archive. Note: if you dont have a dir called BBS:commands
    or a file called customcommands, then just create the directory and
    copy the file there under the name 'customcommands'.

    H         XM010DOORS:AEHELP

(3) Thats it, all your users with access of 10+ will get help simply
    by typing 'H' at any conference (that accepts doors). NOTE: If you
    don't want to replace your current (H) command you can change the
    above 'H' in customcommands to read HELP and it'll supplement
    your current system with an additional HELP option.
