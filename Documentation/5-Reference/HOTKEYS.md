# Hotkeys Reference (Summary)
**Legacy hotkey tables now live in `archive/HOTKEY_REFERENCE.md` and `archive/NAVIGATION_KEYS_REFERENCE.md`.**

- Arrow keys control scrolling; Shift+arrow toggles pages just like express.e's raw mode.
- Function keys (`F1`, `F2`, etc.) trigger sysop menus, chat toggles, and door shortcuts consistent with the Amiga experience.
- Ctrl combinations (Ctrl-X, Ctrl-U) are used inside editors (`E` command) for line operations.

The hotkey system simply reuses the original key mappings; for the full table, review the archived documents.
