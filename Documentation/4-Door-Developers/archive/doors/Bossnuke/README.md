## About This Door

"Bossnuke" is a vintage door program from the 1990s Amiga BBS era. The name comes from BBS terminology of that time period, where "nuke" referred to removing or managing content (similar to "delete" or "clear").

### Historical Context

In 1990s BBS culture:
- "Nuke" = Administrative action to remove/manage files or messages
- Common term in file management and moderation
- Similar to modern "delete", "remove", or "clear" operations
- NOT related to nuclear weapons or destructive attacks

### BBS Terminology

Classic BBS terms that might sound aggressive but have innocent meanings:
- **Nuke** = Delete or remove (file management)
- **Kill** = End a process or close a session
- **Bomb** = Batch operation or mass action
- **War** = Strategy game genre
