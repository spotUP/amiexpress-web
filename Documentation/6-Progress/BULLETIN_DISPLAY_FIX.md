**Issue**: TypeScript implementation skipped displaying SCREEN_NODE_BULL and went straight to confScan, violating express.e:28557.

**Express.e Flow** (lines 28555-28567):
```e
IF subState.subState=SUBSTATE_DISPLAY_BULL
  IF (displayScreen(SCREEN_BULL)) THEN doPause()

  ...

```

**TypeScript Before**:

**TypeScript After**:

- DISPLAY_NODE_BULL: **Display NODE_BULL screen → pause → run confScan** ✅

## Complete Bulletin Display Flow

### Login Flow (Express.e: 28555-28567, 5058)

1. **DISPLAY_LOGON**: Display LOGON screen → pause
2. **DISPLAY_BULL**: Display `Screens/BULL.TXT` → pause
   - Shows bull1-5.txt (MultiTop statistics)
3. **DISPLAY_NODE_BULL**: Display `NodeN/Screens/BULL.TXT` → pause
   - Shows bull6.txt (SAmiLog last callers)
4. **CONF_SCAN**: Run conference scan (check for new messages)
5. **DISPLAY_CONF_BULL**: Display conference bulletin → pause
6. **DISPLAY_MENU**: Display main menu

### Bulletin Files Generated by Batch Commands

**batch0 Commands**:
- `MultiTop`: Generates bull1-5.txt (top uploaders, downloaders, callers, etc.)
- `SAmiLog`: Generates bull6.txt (last callers log)
- `Bulls`: Legacy bulletin generator

**File Locations**:
- `Bulletins/bull1.txt` - MultiTop: Top uploaders
- `Bulletins/bull2.txt` - MultiTop: Top downloaders
- `Bulletins/bull3.txt` - MultiTop: Top upload/download
- `Bulletins/bull4.txt` - MultiTop: BBS statistics
- `Bulletins/bull5.txt` - MultiTop: Call statistics
- `Bulletins/bull6.txt` - SAmiLog: Last callers
- `Bulletins/lastc.txt` - Legacy last callers (displayed in BULL20!.TXT)

### MCI Code Processing

The ~SS_ MCI code is processed by `displayScreen()` in `handlers/screen.handler.ts`:
- `~SS_BBS:path` - Display file from BBS root
- `~SS_NODE:path` - Display file from NodeN directory
- Files are expanded inline during screen rendering
