# Contributing to AmiExpress BBS Door SDK

Thank you for your interest in contributing! This SDK is community-driven and we welcome all contributions.

## Ways to Contribute

1. **Report Bugs** - Found a bug? Open an issue with details
2. **Suggest Features** - Have an idea? We'd love to hear it
3. **Submit Code** - Fix bugs, add features, improve docs
4. **Create Examples** - Share your awesome doors as examples
5. **Write Documentation** - Help others learn the SDK
6. **Test & Feedback** - Try the SDK and share your experience

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/sdk.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Test thoroughly
6. Commit: `git commit -m "Add amazing feature"`
7. Push: `git push origin feature/my-feature`
8. Open a Pull Request

## Code Style

- Use TypeScript for all new code
- Follow existing code style
- Add JSDoc comments for all public APIs
- Include examples in documentation
- Write tests for new features
- Run `npm run lint` before committing

## Documentation

- Update README.md if adding major features
- Add API docs in `docs/API_REFERENCE.md`
- Create tutorials for complex features
- Include code examples

## Testing

- Test in preview mode: `npm run preview`
- Test with real BBS if possible
- Ensure compatibility with 80x24 terminals
- Test ANSI rendering

## Submitting Examples

We love seeing what you create! To submit an example door:

1. Create directory: `examples/your-door/`
2. Include:
   - Main code file
   - package.json
   - README.md
   - Assets (if any)
3. Add entry to examples list
4. Test thoroughly in preview mode
5. Submit PR

## Questions?

Open an issue or join our community discussions!

Thank you for contributing! 🎮
