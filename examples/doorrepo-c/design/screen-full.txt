Legend
------

  B  One box, full width, label in the top border: the door's name for the
     file browser, "History" for the log, the document's node name for
     AmigaGuide.

  T  Text, 20 rows at this size, painted line for line and CLIPPED, never
     re-wrapped. This region is the reason these screens exist: Amiga
     documentation is written to 80 columns, and a 51-column window wraps
     every line of it. DOOR-WRITTEN.

  F  Footer / status line.

Notes
-----

- The history screen paints failures in red and everything else in white.
  If you want a different signal for a failed action, say which.

- AmigaGuide documents are rendered node by node with numbered links. The
  links are part of the text; do not design over them.

- The file browser shows one directory at a time, with sizes right-aligned
  and directories marked. ENTER opens, B goes up.
