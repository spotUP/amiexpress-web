Legend
------

  B  One box around the whole screen, label in the top border.
     "Doors on this board" / "Installed by DoorRepo".

  L  One door per row: command, name, size, and whether it is enabled.
     The selected row is reverse. ENTER runs it, F browses its files.
     DOOR-WRITTEN.

  F  A single footer line inside the box's bottom area:
     "ENTER=Run  F=Files  Q=Quit".

Notes
-----

- This list can be long - 160 doors on the live board - so it pages.
  Nothing may depend on the list being short.

- A door the sysop has DISABLED must read as disabled at a glance. Today
  that is a colour change on the row; if you have a better idea, this is
  the screen to show it on.
