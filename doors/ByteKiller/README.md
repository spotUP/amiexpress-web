# ByteKiller - File Compression Utility

**Type:** File compression/decompression utility
**Era:** 1990s Amiga software
**Platform:** Amiga BBS door program
**Category:** File Utility (like ZIP/RAR)

---

## About This Door

"ByteKiller" is a **file compression utility** from the 1990s Amiga era. Despite the dramatic name, it's simply a data compression tool - the "Killer" refers to "killing bytes" (reducing file size), similar to how modern ZIP or RAR compressors work.

### What It Does

- **Compresses files** to save disk space (disk space was precious in the 1990s!)
- **Decompresses files** back to original form
- **BBS door integration** for uploading/downloading compressed files
- **Similar to:** WinZip, 7-Zip, RAR (modern equivalents)

### The Name Explained

"Killing bytes" was 1990s slang for:
- Reducing file size through compression
- "Killing" redundant data to save space
- Making files smaller for faster modem transfers

**Modern Equivalent:** "Data compression" or "file shrinking"

### Historical Context

In the 1990s:
- Modems were slow (2400-14400 baud)
- Disk space was expensive (hard drives measured in megabytes!)
- File compression was essential for BBS file transfers
- Dramatic names like "ByteKiller" were common marketing

---

## Technical Details

- **Algorithm:** LZ-based compression (similar to DEFLATE, LZW)
- **File Type:** Motorola 68000 executable (Amiga binary)
- **Purpose:** Reduce file sizes for storage/transfer
- **Execution:** Via MOIRA CPU emulator (sandboxed)
- **Safety:** Cannot harm files or system

### Compression Ratio

Typically achieved 30-70% compression on:
- Text files
- Program executables
- Graphics files
- Archive collections
